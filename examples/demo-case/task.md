# Demo task

Turn the synthetic paper in the same directory into an evidence-bound
Nanopublication-style result:

- split each compound conclusion into single, independently checkable assertions;
- keep conditions (current density, cycle count, baseline, electrolyte) with the
  assertion they qualify;
- bind each assertion to a minimal verbatim quote and a paragraph id;
- mark direct evidence versus inference;
- record paper metadata (DOI, title, authors, year, version, license);
- run quality checks for over-broad assertions, missing evidence and subject confusion;
- export a machine-readable structure.

Anything the material does not state must be reported as an uncertainty. This is
a synthetic example, not official case output.
